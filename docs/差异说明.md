# 实现差异说明

本文档记录新版实现与旧版 `robot/` 参考项目之间的**有意差异**、**已知限制**与**待办事项**。

## 1. 已完成的迁移

| 项目 | 结果 |
|---|---|
| 包数量 | 18 个（7 个接口包 + 11 个功能包）；已移除兼容包 `robot_interfaces` |
| 接口数量 | 94 个 msg/srv/action（7 个域包） |
| 构建 | `colcon build --base-paths src` 全绿 |
| 测试 | 533 个用例，0 失败，1 跳过 |
| 包级重名 | 无（旧项目不在构建范围内） |

## 2. 命名与接口差异（有意）

1. **移除 `/v2` 前缀**：所有服务/话题按域重新命名（`/v2/submit_order` → `/business/submit_order`，`/v2/set_chassis_mode` → `/chassis/set_mode` 等），完整对照见 `需求文档.md` 附录 B/C。
2. **移除兼容包**：`robot_interfaces` 不再存在，同名消息统一归属域包（core/navigation/facility）。
3. **成员变量规范化**：旧版 76 个 `v2_*` 标识符已全部去前缀；`*_srv_` → `*_service_`，`*_pub_/_sub_` → `*_publisher_/_subscription_`。
4. **节点参数**：底盘控制模式参数为 `mode`（与旧版启动参数一致），不再使用 `control_mode`。

## 3. 行为兼容性处理

| 项目 | 处理方式 |
|---|---|
| 文本协议 ODOM | 编码输出 5 数值（`x y yaw vx wz`）+ 可选电池；解码兼容 5/6/7 数值（含旧版带电池与全向扩展） |
| 文本协议 CMD | 编码 3 参数；解码兼容 2 参数（`CMD vx wz`）与 3 参数 |
| Mick `0xA1` | 解码兼容 12 字节（旧版）与 14 字节（含横向速度） |
| Mick `0xA2` | 解码兼容空载荷、1 字节、3 字节 |
| 速度指令编码 | 超限/非有限值饱和处理（不抛异常），保证节点不退出 |
| 运动学模型 | `omni→mecanum`；`ackermann/acker/four_ws4wd/4ws4wd/four_wheel_steer→diff_drive`；未知值按 `diff_drive` |
| 位姿积分 | 使用区间起点航向（与旧版数值一致） |
| 后端名称 | `Name()` 返回 `mock` / `serial` / `udp`，`/chassis/state.backend` 语义不变 |

## 4. 已知限制

| 编号 | 限制 | 影响 | 处理 |
|---|---|---|---|
| L-01 | 本机（VMware）无 3D 渲染，Gazebo 无法创建渲染窗口 | `amr_demo` 无法在此机器运行；仿真运行时测试跳过 | 在有 GPU 或 VNC 虚拟桌面的环境运行（`export DISPLAY=:1`）；测试可用 `ROBOT_SIM_RUNTIME_TEST=1` 强制 |
| L-02 | `robot_tasks/src/mission_runner_node.cpp` 仍有 6224 行 | 可维护性 | 见 §5 待办；不影响功能与测试 |
| L-03 | `robot_hardware` 仍为扁平文件布局（未按 `protocol/ transport/ kinematics/ system/ ros/` 拆分，类型仍保留 `Chassis*` 前缀） | 与需求文档 AR-03/附录 G 的目录规划不一致 | 见 §5 待办；不影响功能与接口 |
| L-04 | 旧版 `scripts/` 验收脚本与 `tools/operator_console.html` 未迁移 | 无历史外部脚本兼容 | 需求已声明不保证旧脚本兼容；新版提供 `tools/check_conventions.py` |

## 5. 待办（不阻塞当前交付）

1. **拆分 `mission_runner_node`**：把服务处理器下沉到 `robot_tasks` 库（mission/station/facility/fleet/business 子模块），节点壳保留参数/定时器/注册；目标 ≤1500 行。
2. **`robot_hardware` 分层重构**：按需求文档 AR-03/附录 G 拆目录、加命名空间（`protocol/transport/kinematics/system`）、类型去 `Chassis` 前缀；需同步更新所有 include 与 CMake。
3. **补充命名/契约 CI**：将 `tools/check_conventions.py --strict` 与接口字段 diff 纳入流水线。
4. **仿真渲染环境**：在 GPU/VNC 环境跑通 `amr_demo` 并记录 5 分钟稳定性结果。
