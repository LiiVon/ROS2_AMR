### P1-04 Gazebo 仿真在本机无法运行（EGL/OpenGL）

**现象/证据**

`ros2 launch robot_bringup amr_demo.launch.py gui:=false use_rviz:=false` 输出：

```text
[gz-1] [Err] Unable to create the rendering window:
  OGRE EXCEPTION(3:RenderingAPIException): eglInitialize failed for device
  ... /dev/dri/card0 ...
[gz-1] [Err] OpenGL 3.3 is not supported. Please update your graphics card drivers.
[gz-1] Segmentation fault (Address not mapped to object [0x220])
[ERROR] [gz-1]: process has died [exit code -11]
```

环境：`DISPLAY` 未设置；Mesa/EGL 库已安装；当前用户在 `video`/`render` 组，
`/dev/dri/renderD128` 可读；`LIBGL_ALWAYS_SOFTWARE=1` 与
`GZ_SIM_RENDER_ENGINE=ogre` 均未改变失败结果。

**影响**

- `amr_demo`、`sim.launch.py`、Gazebo 下的 SLAM/Nav2、两机器人车队演示、
  RViz 标签可视化均无法在本机验收；
- 唯一跳过的测试就是 Gazebo 运行时用例；
- README 宣称 `gui:=false` 可用于 headless，但未说明 GPU/EGL 前置条件。

**建议**

1. 在 README/需求文档写明：headless 仍需可用的 EGL/OpenGL 3.3（或 3D 加速的
   虚拟机设置），并给出 `eglQueryDevices`/`glxinfo`/`gz sim` 自检命令；
2. 为 `sim.launch.py` 增加轻量自检：启动前检测 EGL/OpenGL，失败时打印明确
   指引而不是段错误；
3. 可选：提供“无相机/无渲染传感器”的 headless 世界（仅雷达可用假数据），
   或提供 `use_gazebo_sensors:=false` 参数；
4. 在具备 GPU 的主机完成 G13 门禁。

**验收**

- GPU 主机：`amr_demo gui:=false` 下 Gazebo 存活、自动任务完成；
- 本机：launch 在渲染不可用时给出可读错误并非 0 退出，而不是段错误。

### P1-06 仿真时间（`use_sim_time`）未贯通任务/导航节点【本轮已修复】

> **本轮修复：** `mission_runner.launch.py` 新增 `use_sim_time` 参数，`amr_demo`
> 的任务/导航节点传 `true`；实测 `ros2 param get /mission_runner_node use_sim_time`
> 返回 `True`。

**现象/证据**

- `src/robot_tasks/launch/mission_runner.launch.py` 的 launch 参数列表
  （约 90–120 行）没有 `use_sim_time`；
- `src/robot_bringup/launch/amr_demo.launch.py` 中 `mission_runner` 与
  `navigate_sequence_server_node` 均未设置 `use_sim_time`；
- `sim.launch.py` 中 Gazebo 相关节点明确使用 `use_sim_time: True`；
- 任务中枢在 `part_3.inc:546`、`part_4.inc:1392` 等处用 `now()` 生成
  `PoseStamped` / 事件时间。

**影响**

- 全量仿真（`/clock` 生效）时，任务/导航节点使用 wall clock，Gazebo/TF/odom
  使用 sim time，可能出现目标时间戳与 TF 不一致、超时/ETA 计算偏差；
- `amr_demo` 使用内部仿真运动，影响相对有限，但时间基准仍不一致；
- 用户无法通过 launch 参数开启仿真时间，只能手工 `--ros-args -p use_sim_time:=true`。

**建议**

- 在 `mission_runner.launch.py` 增加 `use_sim_time` 参数并传给节点；
- `amr_demo` / `sim` 场景传 `true`，`navigate_sequence_server_node` 同步设置；
- 增加 sim 场景下的时间戳一致性测试。

**验收**

`ros2 param get /mission_runner use_sim_time` 在 sim 中为 true；Nav2 仿真导航
无时间戳外推告警；任务事件时间与 `/clock` 同基准。
